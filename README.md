# 变量面板

RisuAI 插件 —— 酒馆助手风格的聊天变量编辑器。在聊天界面一键打开变量表,直接查看、编辑、新增、删除当前聊天的变量,不再需要记 `/setvar key=xxx` 命令。

## 功能

- **聊天变量表**:读写当前聊天的变量,与 `{{getvar}}` / `{{setvar}}` / Lua `chatvar` / `/setvar` 命令完全同源,按聊天隔离
- **JSON 友好**:JSON 对象/数组自动格式化展示、标记 JSON 徽章,保存时自动压缩回单行;坏 JSON 红框提示
- **未写入的默认变量**:角色/预设里定义了默认值但本聊天尚未落地的变量单独列出,一键写入
- **全局变量·覆盖**:管理本聊天对全局变量的覆盖层(`{{getglobalvar}}` 优先读取),新增时可先查询当前全局值
- 搜索过滤、新增/重命名/删除、未保存更改计数、聊天切换保护(切换聊天后不会写错位置)
- 两个入口:右上角悬浮按钮 + 聊天输入框 `⋮` 菜单里的「变量面板」

## 安装

RisuAI → 设置 → 插件 → 导入插件,选择本仓库里的 `variable-panel.js`。

要求 RisuAI 2025 年以后的版本(插件 API v3.0)。

## 使用

1. 打开任意角色的聊天,点右上角 🧮 悬浮按钮(或输入框旁 `⋮` 菜单 → 变量面板)
2. 直接在表格里改值,`＋ 新增` 加变量,`✕` 删除
3. 点 **保存**。保存后界面上的 `{{getvar}}` 内容会随消息重渲染而更新;如果卡片的状态面板没有立刻刷新,随便发一条消息即可

## 实现说明

| 层 | 存储位置 | 读写方式 |
|---|---|---|
| 聊天变量 | `characters[i].chats[chatPage].scriptstate`(`$` 前缀键) | `risuai.getCharacter()` 快照 → 修改 → `risuai.setCharacter()` 写回 |
| 全局变量覆盖 | 同上 chat 对象的 `GLGlobalVariables` | 同上 |
| 默认变量预读 | 角色 `defaultVariables` + 预设默认值 | `risuai.parseRisuChat('{{getvar::key}}')`(走宿主侧完整回退链) |

保存时重新读取最新角色数据并只覆盖变量字段,避免用旧快照整体覆盖;
若打开面板期间切换了角色/聊天,保存会被拦截并提示刷新。

数据库级的全局变量(`db.globalChatVariables`)在插件沙箱的可访问字段白名单之外,
插件既读不到也无法写,所以全局变量只提供"本聊天覆盖"这一层。

## 开发

单文件插件,无构建步骤。改完 `variable-panel.js` 后在 RisuAI 里:

设置 → 插件 → `</>` 菜单 → Import plugin with hot reload,即可热重载调试。
