# Variable Panel v1.2.0

- Compact desktop rows: single-line values no longer reserve two lines.
- Long text/JSON is capped at 84px, expands on focus, and scrolls internally.
- Responsive phone layout, wrapping toolbar, larger touch controls, 16px inputs, dynamic viewport height and safe-area padding.
- Existing update URL retained. RisuAI checks for updates and asks before installation; this is not unattended auto-installation.

Download variable-panel.js below and import via Settings → Plugins. Existing installations with an update URL can use the update button.

Validation: browser preview with synthetic data, narrow viewport layout, JSON expansion, editing and saving. Physical iOS/Android keyboards have not been tested.
