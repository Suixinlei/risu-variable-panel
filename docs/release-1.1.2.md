## 变量面板 v1.1.2

RisuAI 聊天变量编辑器：查看和编辑聊天变量、JSON 值、默认变量和全局变量覆盖，并支持 setvar 宏即时更新。

### 安装

下载下方 Assets 中的 **variable-panel.js**，在 RisuAI → 设置 → 插件 → `+` 导入。进入聊天后点击 🧮 打开面板。不需要下载 Source code，也不需要编译。

### 本版变化

- 修复 setvar 裸键与平台 `$` 前缀存储键的映射。
- 内置 GitHub 更新地址，可从插件列表获取后续更新。
- 补充中英文安装指引、MIT 许可证、界面截图与反馈说明。

需要插件 API 3.0。跨版本、桌面端与移动端兼容性尚未完成验收。检查范围与复现步骤见仓库 docs/verification.md。
