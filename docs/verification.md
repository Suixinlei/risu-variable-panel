## 可重复的 E2E 验收

使用独立测试角色和聊天，记录 RisuAI 版本/提交号、平台、浏览器和插件版本。

1. 从 Release 下载 JS，通过设置 → 插件 → `+` 导入。确认版本为 1.1.2，进入聊天能打开 🧮 面板。
2. 新建变量 `demo_score`，值为 `10`，保存、关闭再打开；预期仍为 `10`。
3. 改为 `20` 后保存并刷新页面；预期持久化。用 `{getvar::demo_score}` 验证读到 `20`。
4. 新增 JSON 值 `{"hp":100}`，确认格式化展示；输入无效 JSON，确认错误提示且不写入无效数据。
5. 改名、删除并分别保存，再打开确认结果；切换到另一聊天，确认变量隔离。
6. 在面板有未保存更改时切换聊天，确认旧面板不会写入新聊天。
7. 测试卡让输出包含 `{setvar::demo_score::30}`，在真实输出流程完成后检查面板立即显示 `30`；下一轮后值不发生重复累加。
8. 测试角色默认变量写入、全局变量覆盖新增和删除，确认与宏读取一致。
9. 从较旧版本使用插件列表更新，确认升级至当前版本且变量保留。
